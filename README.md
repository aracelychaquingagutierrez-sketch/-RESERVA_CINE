# Objetivo
El programa crea una matriz de 3 filas y 4 columnas que representa los asientos de una sala de cine. El usuario ingresa una fila y una columna par reservar un asiento, 
el cual se marca con el número 
finalmente se muestra la sala completa actualizada.
# cómo ejecutar
Abre el archivo @Reserva_cine.py en python
Ejecutar el programa
Escribe la fila(0, 1 o 2) y presiona Enter
Escribir la columna(0, 1, 2 o 3)Enter
Se mostrará la sala con el asiento reservado
